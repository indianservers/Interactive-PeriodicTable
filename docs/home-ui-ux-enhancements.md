# Home screen: 25 UI and UX enhancements

Suggested follow-up work; these are recommendations, not changes implemented in this update.

1. **Pin favorite tools.** Give each library item a bookmark action and show a compact pinned row near the top.
2. **Resume the actual last lesson.** Make Continue learning use the last saved activity and its real progress.
3. **Replace demonstration mastery values.** Derive mastery and learning streaks from completed activity; show a friendly empty state for new learners.
4. **Make recent experiments real.** Populate the recent list from visited or completed experiments, with timestamps.
5. **Show difficulty badges.** Label content Foundation, Intermediate, or Advanced using reviewed metadata.
6. **Add time estimates.** Show approximate lesson or activity duration where that information is known.
7. **Link prerequisites.** Let learners see what they should understand before opening an advanced concept.
8. **Offer goal-based starting points.** Add entry paths such as Explore a concept, Run an experiment, and Prepare for an exam.
9. **Preserve filters on return.** Save category, subcategory, query, and scroll position when a learner opens a tool and returns Home.
10. **Collapse library groups.** Allow learners to expand only the subcategories they want, with an Expand all control.
11. **Offer compact and visual views.** Keep image cards for discovery and a dense list for frequent users.
12. **Add useful sorting.** Support alphabetical and recently used ordering without inventing popularity data.
13. **Highlight search matches.** Emphasize matching terms in titles and descriptions so results are easier to scan.
14. **Add chemistry search aliases.** Recognize related terms such as pH/acidity, CFT/crystal field, and stoichiometry/limiting reactants.
15. **Navigate search results with the keyboard.** Support Arrow keys, Enter, and Escape, with a visible focus state.
16. **Turn the shortcut into a command palette.** Let Ctrl/Cmd+K find and launch tools without scrolling the page.
17. **Provide a first-visit starting point.** Offer a short optional introduction and a recommended foundation activity.
18. **Label experience types.** Distinguish simulators, references, practice activities, and builders before users open them.
19. **Show molecule-loading feedback.** Display a lightweight skeleton or progress state while the 3D model initializes.
20. **Provide a WebGL fallback.** Show a useful static molecule image and explanatory text when 3D rendering is unavailable.
21. **Respect motion and visibility preferences.** Pause the molecule when offscreen or the tab is hidden, and honor reduced-motion settings.
22. **Add a text alternative to the 3D viewer.** Provide a keyboard-readable atom/bond list and selected-atom details.
23. **Standardize touch targets.** Give compact controls at least a 44px touch area without making the whole layout larger.
24. **Improve mobile navigation.** Provide easy access to Home, Search, Categories, and Saved, and close the drawer after navigation.
25. **Remember display preferences.** Persist compact view, preferred categories, and whether the molecule preview is expanded.

Suggested first priorities: real learner data (2–4), return-state preservation (9), experience labels (18), and reliable 3D loading/fallback behavior (19–22).
